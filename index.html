Motorkalkulator
Beregner virkningsgrad, reaktiv effekt og kondensatorkompensering for elektromotor.
η = P‑avgitt / P‑tilført
QL = P × tan φ
IC = QC / U
XC = U / IC
C = 1 / (2πf · XC)

Ifør = Pfase / (U · cos φ)
Ietter = Pfase / (U · 1)

Jordingskalkulator
Beregner maksimal jordelektrodemotstand Ra og anbefalt elektrodedimensjon for IT-nett iht. FEF / NEK 400-5-54.
Ra × Id ≤ Uc
Uc = 50 V (normal)
Uc = 5 V (tørke/frost)

Jordband: 20×3 mm
Dybde: 0,5 m
Stav: ⌀20 mm
Inndata
⚡ Fyll inn verdier ovenfor
TN-nett — jordfeilberegning ikke nødvendig
TN-nett bruker automatisk frakobling via overstrømsvern (NEK 400-4-41). Krav Ra × Id ≤ Uc gjelder ikke for TN — overstrømsvernet sikrer frakobling ved jordfeil.

Ref: NEK 400-4-41 · Elbok §5.3 — TN-nett: overstrømsvern og frakobling
